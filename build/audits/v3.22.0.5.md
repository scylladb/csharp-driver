# v3.22.0.5 cutoff audit

Baseline: published `v3.22.0.4`. Candidate source cutoff: `12db9e373f56f03c2221b7c857c0df0dfaf2eb41` on `branch-3.22`. The range contains 96 commits and 46 first-parent changes. The release-candidate version and validation changes are outside this source cutoff.

## Compatibility disposition

- Shipping target remains `netstandard2.0`. The existing C# 7.1 pins and four test targets remain in place. The SDK pin moved to 9.0.318 before the maintenance policy was established.
- ApiCompat, using the published `3.22.0.4` packages as the left side, reports no public API removals in the core, AppMetrics, or OpenTelemetry assemblies. The package validator also checks dependency groups and runs a local-feed consumer.
- The only new members on externally visible types in the aggregate shipping diff are `Builder.WithDriverConfigReporting(bool)` and `Configuration.DriverConfigReportingEnabled`. They were introduced before the maintenance policy, remain public, default to enabled, and are documented in the README. Other added `public` declarations are members of internal types.
- Startup reporting (`SESSION_ID` and `DRIVER_CONFIG`), metadata ID negotiation, client routes discovery, and cluster-scoped prepared caching change internal protocol and caching behavior without removing public signatures. They were merged before the maintenance policy. The prepared cache keeps payload-specific prepares separate; fixes after the cutoff preserve that behavior.
- Query, connect, and request maximum setters now reject values that would make every request fail. This is an intentional correctness constraint; applications relying on those invalid values will receive an earlier exception. No other known behavioral incompatibility was found in the cutoff review.
- Shipping dependencies changed within the range. The package validator checks the exact resulting nuspec groups, audits the restored transitive graph, and exercises all three packages in a local-feed consumer. Test and documentation dependency changes do not enter shipping packages.
